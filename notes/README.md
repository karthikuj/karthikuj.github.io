# Notes

Working notes for future posts: ideas, outlines, things to test and links to read. Nothing in this folder
is built into the site. Astro only publishes `src/`, so you can write freely here.

> **This repo is public.** Anything committed here can be read on GitHub. Keep notes that aren't ready
> to be seen (for example unreported findings) out of git: put them in `notes/private/`, which is
> ignored, or anywhere outside the repo.

## How to use it

- One file per post or series, named after its slug: `securing-a-section-of-windows.md`.
- Copy `_template.md` to start a new one.
- When a post is ready to draft, move the outline into `src/data/blog-posts/` with `draft: true` (see
  `docs/publishing-a-post.md`), and leave a pointer here.
